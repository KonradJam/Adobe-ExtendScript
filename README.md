A growing collection of professional ExtendScript automation tools designed for **Desktop Publishing (DTP)**, **Pre-press**, **Print Production**, and **Graphic Design** workflows.

## 🚀 General Installation

### Prerequisites
- Adobe Creative Cloud or CS6+ (tested on InDesign CS6 and CC 2024/2025)
- Basic familiarity with Adobe Scripts Panel

### Installation Steps

1. **Download the script:**
   - Navigate to the script folder you want to use (e.g., `InDesign/Print-Prep/`)
   - Download the `.jsx` file

2. **Install to Adobe Scripts folder:**
   
   **Windows:**
    `C:\Program Files\Adobe\Adobe [Application] [Version]\Scripts\Scripts Panel\`

    **macOS:**
    `/Applications/Adobe [Application] [Version]/Scripts/Scripts Panel/`


3. **Access the script:**
- Open your Adobe application
- Go to `Window > Utilities > Scripts` (or `Window > Automation > Scripts`)
- Double-click the script name to run

> **Tip:** You can also run scripts directly via `File > Scripts > Other Script...` without copying to the Scripts Panel folder.
